# LEARN-MEDIA-DETAIL-001：媒体详情与视频学习器视觉设计

- 日期：2026-09-15
- 状态：已建立并落实到 `LEARN-MEDIA-DETAIL-002/003`，进入产品复核
- 适用范围：个人 Alpha、Next.js 响应式 Web/PWA；电脑端 Web 为主要验收环境
- 依赖：`MEDIA-001`、`VIDEO-001`、`PODCAST-001`、`LEARN-HOME-003`
- 依据：[自动内容供应与词句学习重构设计](2026-09-12-automated-content-supply-and-lexical-learning-redesign.md)、[Language Reactor 技术/UX 调研](2026-09-12-language-reactor-technical-ux-research.md)

## 1. 任务目的

`/learn` 首页已经是内容优先的媒体资料库，但卡片点击后的媒体详情仍主要沿用 `MEDIA-001`/`VIDEO-001` 的功能基线。本任务建立详情页和媒体学习器的独立视觉与响应式规格，使用户从“选择内容”自然过渡到“播放、理解、定位和查词”。

本任务只定义呈现层、交互层级、状态和验收标准，不新增媒体来源、字幕处理、词库、跟读评分、能力画像或数据库字段。

## 2. 不变量与边界

- 详情页只读取已发布、版权清晰、当前可播放的不可变媒体版本。
- 观看、点击字幕、查词、播放进度和学习时长不产生能力证据。
- 无字幕仍可播放，必须明确显示“无逐句辅助”；失败不能伪装成成功或跳转到其他内容。
- 视频使用官方受控嵌入，播客使用原生音频和封面；不下载或代理受限媒体。
- 播放进度继续使用版本号和 revision/CAS；旧 generation 回调不能覆盖当前状态。
- 桌面高密度工具不能原样压缩到手机；播放器控件保留可访问名称，按句切换同时提供左右键和字幕句定位。

## 3. 用户路径

```text
/learn
  → 点击媒体卡
/learn/media/[stableKey]
  → 看标题/来源/时长和播放状态
  → 播放或选择字幕句
  → 左右键按句切换 / 自动暂停
  → 需要时切换双语或点击词语
  → 在当前页面查看词句上下文
  → 返回资料库，或刷新后从版本化进度恢复
```

详情页的首要决策是“播放内容”，不是开始一项新的课程任务；页面不出现 Hero、推荐任务、经验值或独立的“开始学习”按钮。

## 4. 视觉方向

- 延续学习首页的克制深色媒体工作台，但详情页内容区域保持可读的高对比度文本表面。
- 页面使用一个明确的 `h1`，标题、来源、地区、CEFR、时长和字幕状态组成紧凑元信息带。
- 播放器是首屏最大视觉区域；控制、字幕和查词围绕当前媒体组织，不使用装饰性卡片堆叠。
- 颜色只表达当前句、交互焦点、成功同步和错误；状态同时提供文字，不依赖颜色或细线。
- 卡片圆角不超过现有设计系统；播放器、字幕列表和抽屉使用稳定尺寸，避免加载和长标题造成布局跳动。

## 5. 桌面布局（>= 1200px）

采用“主播放区 + 逐句区”的两栏核心布局，并为词句上下文预留按需出现的辅助层，避免把 Language Reactor 的完整三栏工具一次性暴露给首次使用者。

```text
┌─────────────────────────────────────────────────────────────┐
│ 返回资料库                                                   │
│ 类型 · CEFR       标题                                       │
│ 来源 · 地区 · 时长 · 字幕状态                                │
├───────────────────────────────┬─────────────────────────────┤
│ 播放器（16:9）                 │ 字幕与文本                  │
│ 播放状态 / 进度同步             │ 西语 / 双语 / 隐藏          │
│ Plyr 播放控件 / 自动暂停图标     │ 当前句高亮、时间定位、词语  │
└───────────────────────────────┴─────────────────────────────┘
                         词句上下文：右下辅助层
```

- 视频播放区保持 `16:9`；YouTube、托管视频和播客统一使用 Plyr 样式，自动暂停图标位于控制栏，播放器下方只保留状态播报。
- 字幕区独立滚动，当前片段使用背景、左侧强调线和文字状态共同表达；滚动不影响播放器。
- 词句上下文默认不占用主布局；点击词语后在右下显示辅助层，关闭后焦点返回原词语。后续词典/语料任务可以在此层扩展，不改变媒体主路径。
- 低频工具（速度、布局、分享、保存等）若进入实现，默认收纳到次级菜单，不与逐句控制争夺首屏层级。

## 6. 移动布局（< 960px）

- 顶部只保留返回、媒体类型和必要的标题信息；不重复显示账户头像。
- 播放器全宽并尊重安全区，当前句紧随播放器；按句切换使用左右键或直接点击字幕句，自动暂停保留在 Plyr 控制栏。
- 完整字幕进入主滚动区；字幕句仍可点击定位，长句和长标题必须换行而不横向溢出。
- 词句上下文使用底部抽屉，底部位置避开现有五项导航和 `safe-area-inset-bottom`；关闭后焦点回到触发词。
- 320px 至 414px 之间保持单列，不强行保留桌面双栏；触控目标至少 44px。

## 7. 交互与状态

### 7.1 必须保留的核心动作

| 动作 | 可见入口 | 键盘加速器 | 结果 |
| --- | --- | --- | --- |
| 上一句 | 无额外按钮 | `←` / `A` | 定位到上一片段并播放 |
| 重播当前句 | 无额外按钮 | `S` | 从当前片段起点播放 |
| 下一句 | 无额外按钮 | `→` / `D` | 定位到下一片段并播放 |
| 自动暂停 | Plyr 图标按钮 | `Q` | 当前句结束后暂停；无已审核分句时禁用 |
| 字幕模式 | 西语/双语/隐藏分段控件 | 无 | 改变显示，不改变媒体进度 |
| 句子定位 | 时间戳和字幕行 | 无 | 跳到片段起点并更新当前句 |
| 查词 | 句内词语按钮 | 无 | 打开词句上下文辅助层 |

### 7.2 页面状态

- 加载：播放器区域尺寸稳定，显示“播放器准备中…”，不出现空白跳动。
- 就绪/播放/暂停/结束：使用 `status` 文字播报；播放结束保存完成位置。
- 播放失败：保留标题、字幕和重试路径，显示稳定错误文案；不替换成其他内容。
- 无字幕：播放器可用，自动暂停图标禁用，字幕区解释当前没有已审核逐句文本，左右键不改变播放位置。
- 进度保存中/已同步/同步失败/版本冲突：状态位于控制区附近；409 必须要求刷新后继续，不能静默覆盖其他页面进度。
- 媒体下架或地址过期：显示不可用状态和返回资料库入口，不读取旧版本冒充当前版本。

## 8. 可访问性与响应式验收

- 每页一个 `h1`；播放器、字幕区、逐句控制和词句辅助层有稳定 landmark/label。
- 所有仅图标动作有可访问名称，并正确暴露 `pressed`、`selected`、`disabled`、`dialog` 等状态。
- A/S/D/Q 只是加速器，输入框、文本区和可编辑内容中不抢占快捷键。
- 键盘焦点不会被 sticky 播放器、字幕滚动区、底部导航或词句抽屉遮挡；关闭抽屉后焦点回到触发词。
- 在 320、375、390、414、768、1024、1280、1440px 检查无横向溢出、无标题覆盖、无底栏遮挡。
- `prefers-reduced-motion` 下不依赖动画完成状态；错误、空状态和加载状态可由屏幕阅读器理解。

## 9. 与现有实现的差距

当前实现已经覆盖播放器端口、逐句控制、字幕模式、时间定位、词语抽屉和进度 CAS。本任务后续实现阶段需要重点收敛：

1. 详情页标题/来源/播放器/字幕的视觉层级与首页主题一致。
2. 字幕区的滚动、当前句、时间戳和翻译层级更加明确。
3. 词句辅助层在桌面和移动端的定位、遮挡和焦点恢复一致。
4. 加载、错误、无字幕、下架、同步冲突等非正常状态具备完整视觉路径。
5. 真实媒体详情在桌面与移动视口完成截图和交互验收。

## 10. 任务交付与停点

### 2026-09-16 用户确认的布局与字幕修订（LEARN-MEDIA-DETAIL-004）

本修订替代前述桌面比例和标题排版建议：1120px 起视频为约 2:1 的播放器/字幕双栏，播客为约 1:2；更窄视口单列。标题缩小为无衬线，简介默认折叠。字幕西语约 17–18px、行高 1.85，时间戳与译文降低层级；主操作和焦点反馈保留。转写服务的原始说话人编号（如 `S1`）不在学习字幕中展示，底层数据继续保留，后续只有在映射为有意义的角色名称时才重新呈现。

- 桌面字幕列表和移动端页面始终跟随当前句/词；当前播放位置离开可视区域时自动上移，滚轮、触摸或键盘浏览不关闭跟随。首次打开移动页不跳离播放器；不显示“回到当前句”按钮。
- 逐词框选使用真实、经过校验的绝对媒体毫秒与原文 UTF-16 起止偏移，结束边界排除；静音间隙不框词。缺失、越界或重叠数据不估算、不伪造逐词同步。
- 点词复用鉴权的 `/api/v1/read/word-explanation` MiniMax 接口；包含上下文、加载、失败重试、取消旧选择、终态校验和 AI 标记。仅用于理解，不写能力证据、词库或评分。
- 已实现可选词级 DTO/渲染、校验、持久化与转写适配，0034 已在前序应用；现有素材尚未完成真实词级字幕回填。2026-09-16 用户要求暂缓转写/翻译接口工作，当前收尾仅验收 UI 与 fake 测试，不得将 fixture 逐词测试描述为现有媒体已经逐词同步。
- 后续执行修订（2026-09-16）：用户要求字幕转写暂用 MiniMax，翻译暂缓。视频与播客已各生成 MiniMax 词级审核草稿（91/643 段），仍未经过三维审核和显式发布；UI/fake 测试不能替代真实版本发布验收。
- 真实词级上线需要单独验证可提供词时间的转写/强制对齐来源，接通版本化持久化与原有审核发布流程；不跳过审核，不自动调用收费服务或修改生产内容。

本任务交付：本规格、实施计划、状态页登记和现有实现差距清单。设计确认后再领取实现任务 `LEARN-MEDIA-DETAIL-002`，实现任务不得混入 ASR、词库、跟读评分或能力画像。
