# Sueño 公开产品页视觉重设计规格

- 日期：2026-09-20
- 任务：`PUBLIC-HOME-001`
- 状态：方向已获用户批准；ImageGen 不可用，采用浏览器渲染概念等价替代；公开页首版已实现，待用户视觉 review
- 范围：匿名公开入口 `/`，以及该页面的静态素材、动效、响应式和质量验收
- 不在范围：登录后的 `/learn`、`/read`、`/explore`、`/chat`、`/me`；认证、内容、评分、记忆、数据库和 API

## 1. 决策摘要

公开页采用“Quiet Madrid + Apple 式留白”的方向：保留 Sueño 已有的暖纸面、墨绿、砖红和海绿色证据语法，改用更大的排版尺度、全幅媒体和更少的容器。首屏必须展示真实产品界面或真实产品录屏，不再使用 CSS 渐变卡片和伪造的抽象工作台。

动效采用渐进增强：服务端先输出完整内容和静态 poster；原生 CSS scroll-driven animation 负责轻量进入/进度，Motion 负责局部文字和媒体过渡；只有验证确实需要固定滚动叙事时才评估 GSAP ScrollTrigger。第一版不引入 Three.js、持续粒子、漂浮光球或全屏 WebGL。

公开页可以使用营销 Hero；这不改变登录后学习页“打开即真实视频/播客资料库、无 Hero/开始学习 CTA”的产品不变量。

## 2. 研究依据

### 2.1 页面参考

- [Apple iPhone](https://www.apple.com/iphone/)：章节导航、全幅媒体画廊、播放/暂停、滚动时间线和静态媒体降级。
- [OpenAI Codex](https://openai.com/zh-Hans-CN/codex/)：单一视觉焦点，随后按能力、工作流、使用场景和真实反馈展开。直接抓取受到 Cloudflare 限制，页面信息架构通过公开文本镜像核对，不把实现细节当作确定事实。
- [Stripe](https://stripe.com/)：动画波形配静态图片 fallback，辅以 Logo 轮播和渐进式 CTA。
- [Linear](https://linear.app/)：标题逐词淡入、模糊和上移，同时保留完整的可访问文本。
- [Framer](https://www.framer.com/)：作为高质量视觉参考，不引入其运行时模型。

### 2.2 开源工具

| 工具 | 许可/定位 | 本项目决策 |
| --- | --- | --- |
| [Motion](https://github.com/motiondivision/motion) | MIT，React/Vue 动画 | 第一版推荐，用于局部 reveal、布局和交互状态 |
| CSS Scroll-driven Animations | 浏览器能力，无运行时依赖 | 第一版推荐，用于进入视口、进度和轻视差；必须提供 `@supports` 与静态 fallback |
| [Lenis](https://github.com/darkroomengineering/lenis) | MIT，平滑滚动 | 暂不引入；只有媒体时间线同步确实需要时再评估 |
| [GSAP](https://github.com/greensock/GSAP) | GreenSock 自有许可，非 MIT | 暂不引入；若需要 pinned scrollytelling，先复核商业/插件许可 |
| [React Three Fiber](https://github.com/pmndrs/react-three-fiber) | MIT，Three.js React 渲染 | 第一版不引入；无真实 3D 产品对象时不增加 WebGL 负担 |
| [Lottie Web](https://github.com/airbnb/lottie-web) | 开源动画运行时 | 仅在已有设计师 After Effects 资产时使用，不用作装饰填充 |

## 3. 目标用户和转化目标

- 用户：想把认识的西语转化为自然口头表达的成年 A2–B1 学习者。
- 首要转化：进入 `/login`，开始使用 Sueño；不增加支付、订阅或公开注册。
- 次要转化：理解产品与传统题库的差异，建立对真实语境、隐私和证据可信度的信任。
- 语言：中文为主，保留少量有意义的西语短句；不使用大面积英文营销标签。

## 4. 页面结构与可见文案锁

实现前须以此列表为 above-the-fold 和页面文案基线。视觉概念确认后，新增或改写可见文案必须记录为显式偏差。

### 4.1 顶部导航

- 品牌：`Sueño`
- 导航：`产品方式`、`阅读`
- 操作：`登录`、`进入学习`
- 移动端：隐藏次级锚点，仅保留品牌、登录和主 CTA

### 4.2 首屏

- H1：`把认识的西语，变成真正说得出口的话。`
- 支持文案：`通过真实情境、完整表达和新的变式，练习在生活里自然回应。`
- 主 CTA：`进入学习`
- 视觉：真实产品界面或不超过约 12 秒的产品录屏，带静态 poster；不使用伪造数据或未发布内容
- 构图：首屏下方露出下一段内容，桌面和移动端都不能只剩 Hero

### 4.3 语境循环

- 标题：`每一次练习，都在为下一次真实交流做准备。`
- 三步：`先理解情境`、`用自己的话回应`、`带着新变式继续`
- 视觉：开放式纵向步骤或单条时间线，不做三张同构卡片堆叠

### 4.4 产品证明

- 标题：`不是题库，是一张可以回来的生活地图。`
- 证明素材：媒体资料库、字幕/词语学习器、真实对话线程中至少两种
- CTA：`看看沟通目标`
- 素材必须来自当前产品或可授权的产品录制；不把静态概念图当成真实功能

### 4.5 关系和隐私

- 标题：`你的进步属于你，关系记忆也只在你允许时共享。`
- 支持文案：明确 mastery/confidence 分离、技术失败不扣能力、记忆默认隔离
- 视觉：大段留白、短证据列表或单幅关系场景；不使用虚假统计数字

### 4.6 收束 CTA 与页脚

- CTA：`开始第一次练习`
- 页脚品牌短句：`把话说出来`
- 不增加价格、评价数量、用户规模或收益率等未经产品批准的证明

## 5. 视觉系统

### 5.1 色彩

沿用已批准的 Quiet Madrid 语义令牌，但公开页只使用少量表面层：

| 语义 | 建议值 | 用途 |
| --- | --- | --- |
| 页面纸面 | `#F6F3ED` | 页面背景 |
| 浮层表面 | `#FFFCF8` | 产品媒体和局部内容表面 |
| 主文字 | `#17211D` | 标题、正文、导航 |
| 次级文字 | `#5E6863` | 辅助说明 |
| 线框 | `#DDE1DA` | 分隔线和焦点以外的边界 |
| 行动砖红 | `#B94F3B` | 唯一主 CTA、强调动作 |
| 证据海绿 | `#2F7A72` | 隐私/可信状态 |

不使用大面积紫色渐变、霓虹光晕、bokeh/orb、无因果粒子或玻璃叠层。产品媒体若没有色彩覆盖，实施时也不得添加色彩蒙层。

### 5.2 排版和容器

- UI 字体继续使用 `Plus Jakarta Sans` 与中文回退；西语引用可局部使用现有衬线字体。
- 桌面内容最大宽度约 `1180px`，媒体证明段落允许全幅或接近全幅。
- 页面边距：桌面 `28–64px`，移动端 `16px`。
- 标题采用离散断点字号，不使用随视口连续缩放；长标题必须在 375px 下自然换行。
- 页面章节优先使用开放布局、分隔线和全幅 band；卡片只用于真实产品媒体或重复内容，圆角不超过 8px。

### 5.3 图标和按钮

- 使用仓库现有图标风格；没有匹配图标时使用小型 production-quality SVG。
- CTA 使用图标加文字；纯工具按钮使用熟悉图标并提供 tooltip/aria-label。
- 所有交互控件最小触控区 `44px`，焦点环高对比度且不只依赖颜色。

## 6. 动效系统

- 初始 reveal：`opacity + translateY(8px)`，约 `240ms`，最多 4 项 stagger。
- 标题逐词 reveal：只用于首屏或章节标题，不阻塞首屏可读文本；无动画时完整文本直接可见。
- 产品媒体：滚动进入后轻微 scale/translate，避免连续大幅视差；录屏不自动播放有声内容。
- CTA：箭头最多移动 3px，按下缩放约 `0.98`。
- 只优先动画 `transform`、`opacity` 和已验证的 CSS timeline 属性，不动画会引起布局跳动的 width/height/top/left。
- `prefers-reduced-motion: reduce`、低带宽或不支持 scroll timeline 时，保留静态媒体、焦点和内容顺序。
- 页面离屏或标签页隐藏时暂停循环动画；不持续运行无因果的 requestAnimationFrame。

## 7. 技术架构

### 7.1 路由和组件边界

- 保留 `app/page.tsx` 作为公开页入口和服务端文案来源。
- 将交互/动画拆成小型 Client Component，例如 `public-home-motion.tsx`、`public-home-media.tsx`；不要把整个页面变成一个客户端组件。
- 现有产品路由、认证和 API 不变；公开页只使用静态链接和已存在的产品页面路径。

### 7.2 媒体策略

- 优先使用当前产品真实截图或录屏；所有素材声明来源、尺寸、比例和授权状态。
- `<video>` 必须有 poster、`muted`、`playsInline`、合理的 preload 策略和静态图片 fallback。
- 图片使用 Next Image 或等价的响应式加载，不能把 4K 原始素材直接塞进首屏。
- 若概念阶段使用生成图，只能作为背景/过渡资产，不能冒充产品功能界面。

### 7.3 性能目标

- 首屏 HTML 在脚本未执行时仍完整可读。
- 动画不阻塞 LCP；首屏媒体提供明确尺寸，避免 CLS。
- 目标：移动模拟 4G 下 LCP ≤ 2.5s、CLS ≤ 0.1、INP ≤ 200ms；实际结果以 Playwright/浏览器测量为准，不预先宣称通过。
- 首屏之外的媒体和动画使用懒加载；不为宣传页引入大型 WebGL runtime。

## 8. 验收门禁

实现前：

1. 完成分段视觉概念或可验证的等价设计稿。
2. 用户确认概念中的首屏、颜色、章节顺序、媒体处理和 CTA。
3. 建立最终 design tokens、素材清单和 above-the-fold copy diff 基线。

实现后：

- 验证 `375×812`、`768×900`、`1024×900`、`1440×900`。
- 无横向溢出、遮挡、首屏文字裁切、布局跳动和未完成占位。
- 检查键盘焦点、屏幕阅读器语义、reduced-motion、媒体 poster/fallback 和可暂停动效。
- 运行目标 lint、typecheck、相关单测、Playwright 截图回归和生产构建；不把本地截图等同于部署或真机验收。
- 使用 `view_image` 同时检查概念参考和最新实现截图，记录至少五个具体对比点。

## 9. 当前限制

本机可用工具列表中缺少 `imagegen` skill 的实际文件和可调用工具，因此本轮不能宣称已经生成 ImageGen 概念图。本轮使用浏览器渲染的桌面/移动概念等价稿和代码原生产品预览完成首版；后续若图像工具恢复，可补充独立分段概念图，但不应改变已批准的结构、文案和视觉 tokens。
