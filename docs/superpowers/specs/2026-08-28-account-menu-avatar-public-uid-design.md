# 账户入口、头像与公开 UID 设计

## 状态

- **日期**：2026-08-28
- **范围**：个人 Alpha 的账户入口、个人资料编辑、头像和公开 UID 基础
- **设计状态**：已在对话中确认，待用户审阅本文档
- **后续**：文档获批后再进入 writing-plans 和实现阶段

## 背景与问题

当前左下角账户入口只有一个“你”字头像、简单的身份文案和主题切换，无法表达学习产品的成人沉浸式定位，也没有可持续的账户身份基础。账户入口需要同时承担三件事：让用户快速确认“我是谁”，提供低频账户操作，以及为未来的好友关系提供稳定的公开身份。

设计参考了 Duolingo、Busuu、Tandem、Readlang 和 Memrise 的账户、学习身份与个人资料模式，但不复制其儿童化、社交网格化或后台式列表视觉。

## 目标

1. 让账户入口具有“成人语言学习工作室”的编辑感，并在桌面与移动端保持同一信息架构。
2. 让用户能清楚看到、复制和管理自己的公开 UID，为后续精确加好友做准备。
3. 支持可替换头像，同时提供不上传照片也能完成设置的 Sueño 插画预设和首字母回退。
4. 维持学习证据、能力评分、关系记忆和私密对话的隐私边界。
5. 为 Web 与 Flutter 提供稳定的 DTO、预设 ID、错误码和测试契约。

## 非目标与 Alpha 边界

- 本阶段不实现好友关系、好友列表、消息或用户推荐；好友 API 预留在 `/api/v1/friends/*`，待后续阶段单独设计。
- 不支持邮箱搜索、模糊搜索、公开用户目录或基于学习画像的推荐。
- 不实现完整头像社交装扮、头像动效、媒体库或本地离线图片管理。
- 不把 mastery、confidence、连续打卡、学习时长、关系记忆或私密对话放到账户菜单身份卡中。

## 视觉与交互方向：Editorial Studio

### 视觉原则

- 成人沉浸式语言工作室：克制、温暖、可信，强调阅读与表达的节奏。
- 使用现有 Sueño 色彩语义：暖米白背景、深墨绿文字、赤陶色行动色、灰绿色辅助色。
- 采用编辑感的排版层级、细分隔线、窄信息列和清晰的留白；避免儿童化 Claymorphism、霓虹社交网格、卡通吉祥物和后台表格。
- 头像是身份锚点而不是装饰徽章；菜单优先展示姓名、UID 和当前学习语言。

### 账户触发器

- **桌面 Web**：左下角身份行包含头像、显示名、当前目标语言标签和 chevron。点击整行打开约 320px 的弹层，弹层向上展开并避开窗口边缘。
- **移动 Web / Flutter**：顶部使用圆形头像入口；点击后打开安全区友好的底部抽屉，支持向下拖拽或系统返回关闭。
- 触发器必须支持键盘聚焦、Enter/Space 打开、Escape 关闭、点击外部关闭，并正确暴露 `aria-expanded` 与菜单/对话框语义。

### 菜单信息架构

1. **身份卡**：头像、显示名、公开 UID（带复制按钮）、当前学习语言。
2. **编辑个人资料**：进入独立资料页，不在弹层内塞入上传表单。
3. **我的进步与隐私**：沿用现有 `/me` 入口，负责学习状态和隐私控制。
4. **偏好设置**：界面语言、目标语言相关偏好、语音输入偏好等低频设置。
5. **帮助与反馈**：进入帮助/反馈入口。
6. **退出登录**：放在分隔线之后，使用危险操作样式并要求适当的提交状态反馈。

主题切换可继续存在于偏好设置或菜单底部的紧凑控制中，但不得挤占身份卡的主要层级。

身份卡明确不显示邮箱、学习评分、连续打卡、学习时长、好友入口、关系记忆和私密对话。好友入口在阶段 8 之后单独加入，避免现在形成未完成的社交承诺。

## 头像体验

### 编辑流程

1. 用户从账户菜单选择“编辑个人资料”，进入独立资料页。
2. 选择头像来源：**上传照片**、**Sueño 插画预设** 或 **首字母**。
3. 上传照片后进入 1:1 裁剪预览，展示最终在触发器、身份卡和未来好友查找结果中的圆形/方形裁切效果。
4. 用户确认后提交；保存成功才替换当前头像，失败时保留旧头像并提供重试。
5. 删除头像需要二次确认；删除后立即回退到首字母头像。

### 服务端约束

- 服务端二次校验 MIME、文件大小、像素尺寸和内容类型，不能信任客户端扩展名。
- 统一转换为约 512×512 的 WebP，去除 EXIF，生成用于列表/查找的缩略图变体。
- 头像对象使用内部存储路径，不把长期有效签名 URL 写入普通日志或公开 DTO；读取时由服务端生成短期访问地址或使用受保护的图片代理。
- 预设头像使用稳定的 `presetId`，Web 与 Flutter 共用同一枚举和资源清单。
- 首字母头像的字符取显示名首个有效字素；颜色由 `public_uid` 的稳定哈希映射到 Sueño 调色板，确保跨端和改名后的可预测性。
- 头像更新请求带 `attemptId`/版本条件，旧请求完成后不得覆盖更新的头像；对象上传和资料更新均可取消。

## 公开 UID 设计

### 数据模型

`profiles` 增加以下字段：

| 字段 | 类型 | 语义 |
| --- | --- | --- |
| `id` | UUID | 内部所有权 ID，仅用于服务端关联和 RLS，不对外展示 |
| `public_uid` | text | 服务端随机生成、公开、唯一、不可变的 UID |
| `display_name` | text | 可编辑的显示名 |
| `avatar_kind` | text | `upload`、`preset` 或 `initials`，决定头像来源 |
| `avatar_preset_id` | text/null | `avatar_kind=preset` 时的稳定 Sueño 预设 ID |
| `avatar_path` | text/null | `avatar_kind=upload` 时受保护存储中的头像对象路径 |

为兑现“账号删除后 UID 不回收”，增加仅服务端可访问的 `reserved_public_uids` 登记表（`public_uid` 唯一、`reserved_at`、`reason`）。账号删除事务先把 UID 写入登记表，再删除或匿名化 `profiles`；后续生成器同时检查 `profiles` 和登记表。

建议 UID 形态为 `SN-7K4M-9Q2P`：固定前缀、分组显示、易于口述和复制。字符集排除易混淆字符（如 `O/0`、`I/1`），生成不包含时间、邮箱、UUID 或递增信息。

### 生命周期与查找规则

- 创建账户时由服务端生成 UID，并通过数据库唯一索引保证唯一；发生冲突时自动重试。
- UID 不因改名、换头像或更改偏好而变化；账号删除后不回收，避免旧邀请链接指向新用户。
- 本阶段只定义账户自查和资料返回，不实现好友关系。未来精确查找只接受完整 UID 或邀请链接 token，结果最小化返回头像缩略图、显示名和 UID。
- 任何查找接口都必须进行速率限制、输入规范化和失败响应统一化，避免通过差异化错误枚举账户。

### API 边界（设计契约）

- `GET /api/v1/me`：返回当前用户账户菜单和资料页所需 DTO（显示名、public UID、头像引用、当前学习语言及可编辑字段），不返回数据库行类型。
- `PATCH /api/v1/me`：更新显示名、头像引用/预设和允许的资料字段；服务端重新校验所有权、格式和版本。
- 未来好友功能独立使用 `/api/v1/friends/*`，不得让账户资料接口直接写好友关系或关系记忆。

## 隐私、权限与数据流

- PostgreSQL 是资料和公开 UID 的权威来源；资料表继续通过 RLS 保护，服务端 application 用例负责所有权检查和 DTO 转换。
- `profiles.id` 永不出现在客户端可见 URL、复制文本或普通诊断日志中。日志使用内部 hash/ID 关联请求，不记录邮箱、姓名、原始头像或完整私密对话。
- 公开资料只包含用户主动设置且为未来精确社交所需的最小字段。学习证据、画像、评分、录音、AI 角色关系和私密记忆分别存储并保持现有权限边界。
- 头像普通评估流程不保存录音；本设计只涉及图片资料，仍遵循现有数据保留与删除政策。
- 删除或匿名化账户时，先撤销公开 UID 可查找性，再按既有文档化顺序处理资料、头像对象和其他用户数据；UID 本身不重新分配。

## 跨端组件与契约

- Web 的桌面弹层、移动抽屉和 Flutter 的底部抽屉共享同一信息架构、文案键、`presetId`、头像回退哈希和错误码。
- UI 层只消费明确 DTO；React/Flutter 组件不直接访问数据库或供应商 SDK。
- 共享契约样本放在 `contracts/fixtures`，至少覆盖：有照片头像、预设头像、首字母回退、缺少显示名、UID 复制成功/失败和头像更新冲突。
- 移动端适配安全区、系统返回和拖拽关闭；桌面端适配窄屏、缩放和键盘导航。两端均提供加载、空状态、失败和恢复路径。

## 错误处理与竞态

- UID 生成冲突：服务端透明重试，超过上限记录可诊断错误并阻止账户创建完成。
- 头像格式/尺寸不合法：返回稳定错误码和用户可理解的修复提示，不改变当前头像。
- 上传/保存超时或取消：允许重试，旧头像继续可用；取消不产生半成品资料状态。
- 并发编辑：使用版本号或 `updatedAt` 条件写入，检测冲突后要求刷新，不静默覆盖他人或旧标签页的更新。
- 复制 UID：提供短暂成功提示；剪贴板权限失败时展示可选中的 UID 文本。
- 网络恢复：资料页重新拉取服务端状态，避免客户端缓存被当作权威事实。

## 测试与验收标准

### 单元与数据层

- UID 字符集、格式、唯一性重试、不可变性和删除后不回收。
- 首字母字素提取与 UID 哈希调色板在 Web/Flutter 的一致性。
- 头像 MIME/大小/像素校验、WebP 转换、EXIF 清理和旧头像保留。
- RLS 与服务端所有权检查：用户不能读取或修改他人私有资料，也不能通过接口写入好友/学习证据数据。
- 并发更新和过期 `attemptId` 回调不会覆盖最新头像。

### 客户端与端到端

- 桌面弹层：打开/关闭、键盘导航、点击外部、复制 UID、路由到资料页和退出登录状态。
- 移动抽屉：安全区、系统返回、拖拽关闭和相同菜单顺序。
- 头像上传成功、失败重试、删除回退和预设切换。
- 关键路径 Playwright 测试；Flutter 使用 `flutter analyze` 与 `flutter test`。在没有 Mac/Xcode 的环境中不宣称 iOS 编译或真机通过。
- 相关仓库检查按任务范围执行：`pnpm lint`、`pnpm typecheck`、`pnpm test --run`；跨模块迁移或发布候选再补 `pnpm test:e2e` 和 `pnpm build`。

## 决策记录

- 采用 Editorial Studio，而不是儿童化游戏 UI 或社交网格 UI。
- 账户菜单以身份确认和低频账户操作为主，不提前暴露好友入口。
- 公开 UID 不可变、不可回收，只支持精确查找；邮箱不作为社交标识。
- 头像上传、Sueño 预设和首字母回退三路并存，服务端负责最终校验和图像规范化。
