# LEARN-HOME-001：深色媒体学习首页设计与技术规格

- 日期：2026-09-14
- 状态：产品本人已确认方向，待进入实现任务
- 任务：`LEARN-HOME-001`
- 适用范围：个人 Alpha、Next.js 响应式 Web/PWA；电脑端 Web 为主要验收环境
- 视觉参考：用户提供的 B 站电脑端首页与网页首页截图
- 调研依据：`docs/superpowers/specs/2026-09-12-language-reactor-technical-ux-research.md`、`docs/superpowers/specs/2026-08-28-learning-page-desktop-web-technical-research.md`、`docs/superpowers/specs/2026-08-28-learning-page-desktop-web-design.md`

## 1. 方向确认

产品本人确认采用：

- **壳层 A**：紧凑左侧导航栏，顶部搜索和页面频道。
- **主题 B**：深色电脑 App 工作台。

这不是复制 B 站品牌、文案、源码或资源，而是借鉴其内容首页的空间组织：品牌和全局导航稳定可达，搜索位于顶部，内容卡成为首屏主角，页面通过多列媒体流提高浏览效率。

`/learn` 仍遵守 ADR-0008 的入口不变量：登录后直接展示真实可播放/可收听的已发布视频和播客；不出现欢迎 Hero、“开始学习”“继续学习”、任务时间线、虚构推荐或唯一任务 CTA。全部内容卡保持等权，播放进度只能作为卡片次级信息。

## 2. 调研结论

### 2.1 可借鉴模式

1. B 站电脑端的左侧导航释放了内容宽度；导航收缩后仍需通过 tooltip 或展开态保持可发现性。
2. B 站网页首页的顶部搜索和频道导航建立了稳定的内容发现入口；频道不应被拆成多套页面级导航。
3. Language Reactor 的媒体目录证明，内容选择、搜索和筛选应属于同一工作区；复杂工具应在进入媒体学习器后按需出现。
4. Language Reactor 的学习器证明，媒体、句子、词语可以共享稳定的上下文对象；这项抽象属于后续学习器/词库任务，不应在首页堆叠词典工具。
5. 现有媒体发布门禁只公开 `published + cleared + playable` 版本；首页不得读取候选、草稿、撤下版本或其他用户进度。

### 2.2 当前问题根因

- 当前 `MediaCard` 没有 `thumbnail` 或 `cover` 字段，无法呈现真实内容封面。
- 当前媒体卡使用 CSS 占位艺术，不符合“媒体内容本身是首屏视觉主体”的目标；也不能继续用渐变假装真实缩略图。
- 当前页头、类型标签、筛选表单和空状态位于同一纵向流，首屏层级不接近内容首页。
- 当前壳层宽度和学习页内容宽度是全站统一值，没有为媒体首页定义紧凑导航变体。
- 当前媒体列表只提供 `video/podcast`、地区、CEFR、时长和排序，缺少真实封面、字幕状态和发布时间的展示投影。

## 3. 目标与非目标

### 3.1 目标

1. 在 `1440 / 1280px` 桌面视口中形成深色、内容优先的媒体首页。
2. 左侧导航收缩时保留五项一级职责和可访问名称，展开时提供完整标签与账户入口。
3. 顶部提供品牌、`全部 / 视频 / 播客` 频道和全局媒体搜索；频道切换与搜索保留 URL 深链。
4. 首屏优先展示真实媒体封面；没有封面时显示明确的“暂无封面”状态，不使用随机渐变或虚构照片。
5. 让筛选成为次级工具，不占用内容首页的大块高度；保留地区、难度、时长、排序和清除筛选。
6. 让移动端重排为顶部品牌/搜索、横向频道、双列内容和底部五项导航，不把桌面侧栏压缩成不可用的窄栏。
7. 维持现有媒体权限、版本、播放进度、空状态、下架和不可用语义。

### 3.2 非目标

- 不实现个性化推荐、热门榜、播放量、关注、评论、广告或社区模块。
- 不新增媒体学习器、词典、字幕、跟读、评分或能力画像功能。
- 不接入未验证的公网图片代理、第三方截图服务或下载受限媒体。
- 不删除 `/learn/practice`、训练状态机、历史 evidence 或旧数据。
- 不恢复 Flutter 页面同步，不新增独立服务或消息队列。

## 5. 视觉与交互规格

### 5.1 桌面壳层

| 状态 | 宽度 | 表现 |
| --- | ---: | --- |
| 收缩 | 88px | Logo 缩略标记、图标、tooltip、当前态背景和边线 |
| 展开 | 224px | Logo 字标、图标+文字、账户入口；状态由客户端偏好控制 |
| 1024px | 默认收缩 | 内容优先，主区不被导航挤压 |
| `<960px` | 移动壳层 | 隐藏桌面侧栏，使用现有底部五项导航 |

收缩按钮必须有 `aria-label`、焦点样式和 44px 命中区。导航图标不能成为唯一语义来源；tooltip 只作为补充，屏幕阅读器仍读取文字标签。

### 5.2 顶部媒体栏

- 高度约 `64px`，底部使用低对比度分隔线，不使用大面积渐变。
- 左侧为频道导航；当前频道用文字、底部强调线和背景层级共同表达。
- 右侧搜索框约 `320–420px`；输入框有可见焦点环，搜索按钮使用 SVG 放大镜并有“提交搜索”名称。
- 顶部不放账户头像、通知、创作中心、广告或与学习无关的全局操作。
- 移动端搜索可折叠为图标入口，但展开后输入框必须有可见 label、44px 控件和返回/关闭路径。

### 5.3 内容卡

- 桌面：`1440px` 为 5 列、`1280px` 为 4 列、`1024px` 为 3 列；卡片宽度由网格自动计算，不固定像素宽度。
- 移动：`414/390/375px` 为 2 列；`320px` 允许降为 1 列，避免标题和控制互相遮挡。
- 封面固定 `16:9`，预留尺寸避免 CLS；真实图片使用响应式 `img`/Next Image，默认 `loading="lazy"`，首屏第一批可优先加载。
- 卡片正文层级：标题（最多两行）→ 来源/类型 → 时长/地区/CEFR → 字幕状态或真实继续位置。
- 视频与播客只用类型图标区分，不用颜色单独表达状态；播客无封面时显示带耳机图标和“暂无封面”的明确空图块。
- 卡片整体是唯一主链接，点击进入 `/learn/media/[stableKey]`；不在卡片内增加“开始”“继续”按钮。
- 悬停只改变边框/阴影和播放图标状态；键盘 focus-visible 与悬停同等清晰。

### 5.4 筛选与分页

- 桌面默认显示一个“筛选”按钮、已选条件摘要和排序菜单；点击后展开内联工具条或弹出面板。
- 面板字段仍为地区、CEFR、时长、排序；不新增词汇量、播放量、热度或推荐分数。
- 移动端使用底部抽屉；抽屉关闭后焦点返回筛选按钮，不能遮挡底部导航。
- 搜索、频道、筛选和排序写入 URL；刷新和深链恢复状态。
- 分页继续使用稳定 cursor 和“加载更多”，不实现不可控无限滚动。

### 5.5 深色令牌

建议在学习首页专用作用域定义令牌，避免全站临时反色：

```text
--learn-bg: #111315
--learn-surface: #191c20
--learn-surface-raised: #22262b
--learn-line: #30353b
--learn-text: #f1f3f5
--learn-muted: #9aa2ab
--learn-accent: #e76f9a
--learn-positive: #76c7b4
```

正文与控件文字按 WCAG AA 检查；粉色只表示当前频道/交互强调，绿色只表示可继续播放或正向状态。不能使用纯黑背景配纯白大面积文字，也不能用撞色数量胶囊制造虚假热门信号。

## 6. 媒体展示 DTO

`LEARN-HOME-001` 只定义展示契约；字段接入由 `LEARN-HOME-002` 实现。

```ts
type MediaArtwork = {
  url: string;
  alt: string;
  source: "youtube" | "podcast-feed" | "fallback";
  width: number | null;
  height: number | null;
  expiresAt: string | null;
};

type MediaCard = {
  // existing immutable media identity and content fields remain unchanged
  stableKey: string;
  version: number;
  kind: "video" | "podcast";
  title: string;
  summary: string;
  sourceName: string;
  region: string | null;
  cefr: "A2" | "B1" | null;
  durationMs: number;
  publishedAt: string | null;
  curatedAt: string;
  artwork: MediaArtwork | null;
  transcriptStatus: "available" | "unavailable" | "pending";
  progress: MediaProgress | null;
};
```

### 6.1 数据规则

- Artwork 必须绑定不可变媒体版本；版本变化不能静默复用旧封面。
- YouTube 只允许来源策略已批准的官方缩略图；不下载或代理受限视频。
- 播客只使用 RSS 声明且通过 HTTPS/来源 allowlist 校验的封面 URL。
- `fallback` 只代表明确无封面占位图，不允许把 CSS 渐变或随机字母伪装成真实 artwork。
- 外部 URL 需校验协议、主机、长度和过期时间；日志不记录长期签名 URL。
- Artwork 失败不使可播放媒体从目录消失；卡片显示“暂无封面”，详情页仍可打开。
- 公开投影继续只返回已发布、版权清晰、资产可用的当前版本；不把候选字段暴露给客户端。

## 7. 组件与边界

```text
src/modules/media/
├─ domain/media.ts                 # MediaArtwork 和公开 DTO 语义
├─ schemas/media.ts                # artwork URL/alt/expiry 校验
├─ repositories/drizzle-media-repository.ts
│                                  # 只投影公开当前版本和 artwork
└─ ui/
   ├─ media-library.tsx             # 页面编排、URL 查询、空状态
   ├─ media-library-toolbar.tsx    # 频道、搜索、筛选、排序
   ├─ media-card.tsx                # 等权卡片和 artwork 降级
   └─ media-artwork.tsx             # 尺寸、懒加载、无封面状态

src/shared/ui/
└─ bottom-navigation.tsx            # 收缩/展开桌面导航和移动底栏
```

Route Handler 和 Server Component 只负责鉴权、查询参数校验和调用 application；React UI 不直接访问数据库。导航收缩状态是壳层显示偏好，不能影响媒体可见性或学习证据。

## 8. 执行任务拆分

### `LEARN-HOME-002`：媒体 artwork 数据与发布投影

- 扩展 `media_versions` 的版本化 artwork 字段或独立 artwork 表，选择一种可迁移方案并记录 ADR/迁移。
- 更新视频/播客候选处理、发布 publisher、公开 DTO、Zod schema 和 repository 投影。
- 增加 YouTube 官方缩略图与播客 RSS artwork 的 fake 契约测试。
- 覆盖 URL allowlist、HTTPS、过期、缺失、版本切换、撤下和跨用户隔离。
- 不修改 `/learn` 页面布局。

### `LEARN-HOME-003`：深色首页与紧凑壳层实现

- 按本规格实现 88/224px 桌面侧栏、顶部媒体栏、搜索/频道 URL 状态、筛选抽屉和响应式媒体网格。
- 使用 `artwork` DTO；无封面走明确降级，不再使用 CSS 假封面。
- 保留现有播放详情路由、进度 revision/CAS、空/错/下架状态和移动底栏。
- 增加组件测试：导航 aria、卡片等权链接、搜索/筛选恢复、无封面、数据不可用。

### `LEARN-HOME-004`：视觉与响应式验收

- Playwright 覆盖 `1440/1280/1024/768/414/390/375/320px`。
- 浅色主题不属于本任务默认视觉，但必须确认全站主题切换不破坏学习页可读性；深色是主要验收主题。
- 检查无横向溢出、无重复头像、无任务式 CTA、无伪造封面、首屏无内容遮挡、键盘 focus 和移动抽屉焦点恢复。
- 使用自有或固定 fake artwork，不访问公网图片或收费 Provider。

## 9. 验收条件

### 9.1 视觉与布局

- `1440px` 首屏可见紧凑侧栏、顶部搜索/频道和至少两排真实媒体卡，不出现大段说明文案。
- `1280px` 仍保持 4 列；`1024px` 退化到 3 列并默认收缩侧栏；小于 `960px` 使用移动壳层。
- 移动端顶部无常驻账户头像，底部“我的”可达；卡片和筛选不被底栏遮挡。
- 标题、来源和时长在最长 fixture 文案下不互相覆盖；正文控件不低于项目规定的触控尺寸。

### 9.2 真实性与安全

- 页面只显示已发布、版权清晰、资产可用的当前媒体版本。
- 每个卡片直接链接详情，不出现开始/继续任务按钮或虚假推荐解释。
- 无 artwork 时显示明确无封面状态；不以随机 CSS 图形冒充第三方缩略图。
- artwork URL、alt、过期时间和版本绑定通过 schema、repository 和发布测试验证。

### 9.3 行为与可访问性

- 频道、搜索、筛选、排序、分页均可深链和刷新恢复。
- 收缩/展开导航、搜索提交、筛选抽屉和卡片链接均有键盘路径、焦点样式和可访问名称。
- 数据不可用、空结果、无封面、媒体下架和播放失败都保留诚实且可恢复的状态。
- `prefers-reduced-motion` 下不依赖动画完成状态；固定区域不遮挡聚焦控件。

## 10. 当前任务停点

本规格完成后暂停，不直接实施 `LEARN-HOME-002` 或 `LEARN-HOME-003`。产品本人下一步需要分别确认：

1. 是否接受深色首页的 `88px` 收缩栏 / `224px` 展开栏比例。
2. 是否接受没有真实 artwork 时使用“暂无封面”占位，而不是保留 CSS 艺术封面。
3. 是否接受在真实 artwork 数据完成前，首页只用固定 fake artwork 做视觉验收，不访问公网。

确认后按 `LEARN-HOME-002 → LEARN-HOME-003 → LEARN-HOME-004` 顺序执行，每个任务单独验收，不把媒体学习器、词库、推荐或评分功能混入首页重做。
