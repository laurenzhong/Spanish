## 修复

- 对话会话列表显示真实联系人，可关闭、切换或回到当前会话。短横屏联系人列表可以滚动到底，底栏上方留出完整触控区。
- 每条适用的聊天消息提供 44px 触控菜单，保留复制、朗读、翻译、引用、撤回和删除的原有权限。键盘缩小可视区域时，对话和 AI 助手的发送操作跟随可视区，键盘收起后恢复导航。仅高度变化时，历史气泡跳过文本宽度重新测量。
- 聊天录音被页面切换或设备中断时复位，Safari 的 MP4 录音使用匹配的扩展名。聊天和场景实战的回车发送识别输入法的候选确认。场景按住录音按钮避免与页面滚动手势冲突。
- 「我的」手机页增加账户入口，包含个人资料、公开 UID、偏好、主题、帮助和退出。两行分区标签在正确项目下显示活动线。所有者候选较长的标识可在窄屏换行。帮助页从可选的 `SUPPORT_EMAIL` 读取公开联系邮箱。
- 较小手机上的常用文本输入采用至少 16px 字号。文章笔记在键盘上方可编辑和保存，词义面板关闭后回到触发词。探索搜索直接处理输入事件，故事和密码表单以浏览器实际填写的值提交。

## 覆盖与验收

本地用 Windows WebKit 的 iPhone 13 Mini 触屏档案检查 32 个入口和状态，浅色、深色各 32 个，根页面均未出现横向溢出。定向回归使用 320px、375px 和 667×375 横屏，并用可视视口模拟键盘收起和展开。整套浏览器首跑收集 201 项，163 项通过、35 项失败、3 项跳过。之后按修订处复跑专项。首跑汇总包含修复前的结果，无法用于判定最终全站门禁。

- 影音、阅读、探索、画像及所有者工作流专项 36/36。触控、登录、阅读焦点和隐私确认专项 14/14。
- 聚焦 Vitest 10 文件、106/106。TypeScript 与受影响文件 ESLint 通过。生产构建使用单 worker，静态页 77/77。
- 扩展 Vitest 单测批次在对话节奏测试处停止（已通过 419 项，失败 1 项）。全仓 Vitest 未完成。全仓 ESLint 仍有 4 条既有警告。
- 全站浏览器套件未在最终提交上重跑。桌面和移动 Chromium 也参与了登录及触控相关回归。

## 复验

在任务分支安装依赖后，用本地 Playwright WebKit 运行专项。浏览器未安装时执行一次 `pnpm exec playwright install webkit`。

```powershell
$env:PLAYWRIGHT_IPHONE = "1"
$env:PLAYWRIGHT_PORT = "3101"
pnpm exec playwright test --project=mobile-webkit iphone-interactions login
```

真机打开同一版本后，建议先完成登录、底栏五个入口与横屏聊天，再检查聊天和阅读笔记的系统键盘、原声与朗读、首次麦克风权限、切换 App 后恢复。使用独立测试账号才执行注销或候选操作。
