# ADR-0015：词汇例句使用 Tatoeba 原声

- Status: accepted（产品本人 2026-10-13 明确要求例句复制与播放按钮，音频使用 Tatoeba 数据）
- Date: 2026-10-13
- Task: `VOCAB-TATOEBA-002`

## Context

词汇侧栏已使用 Tatoeba 西语例句与中文译文，但未读取录音。句子许可不覆盖音频；Tatoeba 下载页明确说明空音频许可不得在站外重用。ADR-0013 的“不抓取第三方音频”针对未获再利用许可的第三方产物；本决定增加有单独许可的 Tatoeba 例句完整录音，不改变单词朗读策略。

## Decision

- 保留既有例句，不为音频替换原句。使用官方 `sentences_with_audio.csv` 的 sentence ID/audio ID 配对，将许可、录音作者、署名 URL 保存到独立 `es-audio-tatoeba-v1.json` 元数据资产；不保存音频文件。
- 只接受代码列出的明确 Creative Commons 许可，空白与未知许可拒绝。当前实际录音许可为 `CC BY-NC-ND 3.0` 或 `CC BY-NC 4.0`，限当前所有者的非商业 Alpha；ND 音频只完整、原样播放，无裁切、变速、混音或训练加工。未来商业化或多人产品须重新核查许可。
- 导出署名 URL 为空而作者存在时，使用该作者的 Tatoeba 用户主页；API 实测亦使用作者主页署名。许可绝不从句子或作者推断。
- 播放使用官方 API 的 `https://api.tatoeba.org/v1/audios/{audioId}/file`（复数 `audios`），已通过浏览器 GET、真实媒体进度与解码验证；该端点支持 CORS。API 元数据中的单数 `/v1/audio/{id}/file` 不可用，HEAD 也不能替代 GET 验证。网页自身 `/en/audio/download/{audioId}` 的抽检亦能播放，但在本次 Chrome 无声排查中改用明确的官方音频 API；没有证据表明 API 在所有网络中更快或能解决设备静音。域名与路径由代码固定，资产不能注入任意媒体地址。
- 每条例句右侧提供 44px 复制、播放/停止图标；复制只包含西语原句。产品本人在确认原声可播放后明确授权无录音例句使用 TTS（2026-10-13）。无可用授权原声时按钮为“合成朗读例句”，复用已有浏览器西语 TTS；原按钮旁的“暂无录音 · 合成朗读”说明行已按所有者要求于 2026-10-18 移除。点击任一播放按钮不显示准备/加载/播放状态文案（2026-10-18 所有者要求），状态只由按钮图标、停止标签与 aria 属性表达；只有确认 start 才把合成朗读按钮视为正在播放，结束/错误/无声超时复位并允许重试。有录音时只播放原声；原声请求失败可重试，不自动换成 TTS，不混淆来源。
- 共用词架唯一音频元素与 generation；词音与例句音互斥，切词、关闭、Escape、页面隐藏和卸载取消播放、移除 src 并释放加载资源。只有 `currentTime` 实际前进才确认正在播放，`waiting` 仍视为加载中（不再显示状态文案）；开始与中途无进度均最多 20 秒，重复事件但时间不变不能续期。结束、失败和取消清除事件与计时器；过期回调不能更新 UI。
- 元数据提前获取；运行时查词只读本地资产。点击播放才由浏览器向 Tatoeba 请求录音，第三方因此能收到 IP 和常规请求信息。无用户文本、账号或录音上传；不产生学习证据或能力变化。
- 合成例句与单词 TTS/原声共用停止与 generation 生命周期，切词、关闭、隐藏、卸载及换源取消。TTS 只输入公开西语例句，不生成、保存或上传录音；浏览器选择本地/在线西语声音的既有策略保持，在线声音可能由浏览器语音服务处理公开句子。未引入新的收费供应商、API 密钥或持久化。

## Alternatives and consequences

逐句实时查询增加查词延迟及外部依赖；一次官方元数据导出可配对现有例句，且不重新采集文本。代价是导出为快照；撤下或失效的录音由官方播放端拒绝，UI 显示失败，可重建资产移除记录。无原声例句可以阅读、复制和明确标记的合成朗读，不能声称全部例句都有原声。TTS 音色与可用性由浏览器已安装/可用的西语声音决定，不能代替原声听感或发音评分证据。

## Evidence

- [官方导出说明](https://tatoeba.org/en/downloads)：句子 ID、音频 ID、用户名、许可、署名 URL 五列；空许可不得站外复用。
- [官方录音页面](https://tatoeba.org/zh-cn/audio/index/spa)：播放链接 `/zh-cn/audio/download/{audioId}`。
- [API 文档](https://api.tatoeba.org/openapi.json)：`include=audios` 提供单独作者与许可，实际字段名为 `license`。
- 本轮官方导出快照最后修改 2026-10-10，来源 CSV SHA-256 保存在资产。现有 2,087 个独立例句，配对 1,108 条可用录音，覆盖 850 个词；32 条空许可录音被排除。
