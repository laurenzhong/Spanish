# ADR-0016：短语页改为按交际目的组织的表达手册

- 日期：2026-10-15
- 状态：Accepted（所有者明确授权全面重设计）
- 任务：PHRASE-REDESIGN-001

## 背景

正式短语索引为空时，旧页展示二、三词的机械语料片段。用户无法获得完整意义、使用方法或练习价值，来源跳转也不能修复这一问题。所有者明确否定这套设计，授权本次超越旧页面规格。

## 决定

`/read/phrases` 改为版本化原创表达手册，按接话、澄清、观点、邀约、请求和日常办事组织。每条有完整交际表达、中文含义、使用情境、两轮双语对话、语用边界、可替换结构、至少两种替代表达及迁移回想提示。AI 起草后，独立 AI 分别审核西语和中文教学，修订后复验、校验 Schema 并固定内容哈希。

页面直接读取模块内经审核的静态版本，不依赖远程语料扫描。旧来源卡片和筛选表单退出此路由；`/read/corpus` 继续承担真实来源检索、版权与可见性校验。旧短语 API、私有条目及审核索引保留，页面不将其机械结果冒充教学条目。

搜索支持西语重音归一和中文。收藏以账号 ID 隔离保存在浏览器 localStorage，关闭浏览器后保留、不同设备不自动同步，存储失败明确提示；不把它当作服务端学习事实。遮住西语用于回想；情境自测从当前结果随机取不重复的最多五条，先思考、再揭晓参考、自选是否重练，无自动判分、录音或供应商调用。朗读复用已有浏览器 TTS 的取消、过期回调和错误处理。

## 替代方案和后果

仅重排旧卡片不能解决随机截取的内容质量。实时 LLM 解释会增加费用、延迟和审核问题。等待完整自动短语索引又无法交付当下可用页面。因此先交付有明确边界的 24 条审核内容，后续按真实学习需求扩展。原创示例明确标识，不声称来自真实语料。

取代 ADR-0012 中短语页使用代表来源和过渡片段的决定；该 ADR 的语料检索、来源权限、查询语义和证据隔离继续有效。不改变数据库、公共 API、供应商、学习评分或角色记忆。
