# ADR-0019：Web 合成朗读统一 MiniMax 女声

- Status: accepted（2026-10-16 所有者试听后明确选择 MiniMax 女声，并授权现有与未来全部朗读入口统一）
- Task: TTS-READALOUD-001；前置 TTS-AUDITION-001；弱网优化 TTS-LATENCY-001

## 背景与决定

浏览器自带语音的音色、可用性和实际听感因设备而异。所有者在相同文本的 Kokoro/MiniMax 试听中选择 MiniMax Serene Woman。Web/PWA 的**合成朗读**统一使用 `speech-2.8-turbo`、`Spanish_SereneWoman`、Spanish language boost、合成速度1、32kHz/128kbps/单声道MP3；客户端可调整播放速度。该声音属于 AI 合成；供应商目录只标记 Spanish，不宣称经核验的 es-ES 真人或母语发音。

词汇、短语（含逐句与自测）、语料、媒体点词、书架、文章、内容包、训练参考句、场景表达和聊天消息统一经 `createReadAloud` / `useReadAloud` 调用鉴权 `POST /api/v1/tts`。旧 `/conversations/tts` 保留别名。未来入口必须使用相同 API，不直接使用浏览器 `speechSynthesis` 或另选音色。词汇仍只读显示的词，不改成媒体切片；视频/播客与有许可的 Tatoeba 真人录音继续播放原声，原声失败不静默换成合成音。

Route 只做会话鉴权、严格 Zod 请求校验、application 调用与协议转换。Application 依赖内部 provider 接口；API key 仅在服务端。音色/模型由共享 policy 固定，客户端及旧的环境音色变量不能覆盖。端点可按部署配置，模型或声音的后续调整须同步本决策与试听/回归。

## 生命周期、隐私与费用

- 文本超过300 UTF-16字符时，首段最多180字符，后续最多1000字符，优先句子/词边界并保留全文，按需串行合成与播放。较短首段减少首次生成/下载量；可能增加一段请求，后续段间仍有网络等待。没有提前付费生成或自动重试；错误明确可恢复。只有真实 `playing` 才确认播放，换内容、停止和卸载使旧回调失效并释放播放器、对象URL、定时器和请求；单页面同一时刻只有一项合成朗读。
- 用户触发朗读时，当前文本（包括可能的私人聊天/故事/保存项）会发送至 MiniMax；不发送其他上下文、账户邮箱、录音或学习画像。此次所有者授权限个人 Alpha；引入其他真实用户前重新审视告知、同意和供应商条款。供应商自身的处理/保留以其服务条款为准，本仓库未承诺其零保留。
- 不持久化合成文本/音频，不向公共缓存暴露私人内容，不增加录音库。服务端音频只在进程内按 HMAC(userId + text + policy) 隔离复用；随机进程密钥、最多128项/32MiB、成功10分钟定时清除、失败30秒短期拒绝标记。无原文日志或公开音频URL。客户端结束/取消后撤销对象URL，无持久化音频或离线下载。
- TTS-LATENCY-001：同一 `createReadAloud` 控制器只复用已成功完整播放的音频字节；最多8段/4MiB，LRU淘汰，每段最后完成播放后60秒定时释放。不同控制器不共享，首次仍须鉴权请求；短期重播直接播放内存音频，不再次联网鉴权或生成。播放速度在本地应用，不改变合成声音/音质。`stop`（包括hook卸载）、页面隐藏/pagehide、账户退出及Supabase后续会话事件（含跨标签页退出/令牌刷新）清空并取消当前播放；过期或没有缓存/在途播放时释放监听器和订阅。迟到响应、失败/未完成播放不进入复用缓存；缓存不构成访问权或学习证据。不在localStorage、IndexedDB、Service Worker或HTTP缓存中存储私人语音，不为缓存增加服务端数据保留。
- 同进程同用户同文本的并发请求共用一次供应商任务。客户端断开只取消等待，已开始的供应商请求在30秒截止内完成并进入短期缓存，以便后续点击复用。停止播放无法撤回已发送的供应商文本或费用。跨实例、重启、缓存淘汰/到期后可能再次计费；这不是持久化全局幂等保证。不会自动重试结果不明的付费请求。
- 适配器校验响应，记录 provider/model/voice、供应商 requestId、延迟和可用的 billable characters 为内部元数据；未知估算费用和置信度明确为 null，不虚报金额或发音评分。元数据随短期缓存释放，不记录原文/音频/密钥。
- 供应商响应以Content-Length预检和有界流读取限制JSON大小（音频hex上限加64KiB元数据）；分配前限制音频为4MiB，校验ID3与完整首个MPEG Layer III帧再缓存，显式未完成响应拒绝。客户端同样限制音频大小并处理实际解码失败；结构校验不冒称服务端已完整解码每帧。

## 替代方案与后果

Kokoro 保持为已完成的试听方案，Azure 按所有者选择暂缓，浏览器合成仅留历史适配器与测试，不作产品静默兜底。统一声音需要网络和 MiniMax 服务，可能收费；不可用时提供错误和手动重试。此决定取代 ADR-0013 2026-10-13 关于“浏览器 TTS、不新增供应商”的部分；Tatoeba 许可、历史审计、媒体播放、证据/评分规则不变。

验证需覆盖供应商契约、鉴权/用户隔离/去重/失败期限、取消/竞态/音频释放与真实按钮路径。默认测试一律 fake 供应商；Chrome 手机仿真不能代替 iPhone Safari/PWA 真机音频解锁与听感验收。
