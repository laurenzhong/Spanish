# ADR-0017：语料页作为真实用例查询与对照工作区

- 日期：2026-10-15
- 状态：Accepted，所有者授权评估后由代理决定并重做
- 任务：CORPUS-REDESIGN-001

## 背景

词汇页解决词义，120条原创短语手册解决可用说法。语料页仍有独立价值：从真实输入确认用法、比较不同来源的句子并回到原文继续听读。但原默认浏览机械截取2–3词，正式出现索引不足时浏览和搜索使用不同数据源，原文存在却搜不到；来源链接还存在版本与定位缺陷。

## 决定

1. 保留 `/read/corpus` 与单一阅读导航。主标题“语料”，以“在真实内容里，查清一个词怎么用”为用途，默认展示跨来源轮换的原段落/字幕。无译文的文章长段超过360字符时，按西语句界显示完整命中句（多个命中保留中间句），未搜索时显示开头两句；展开保留完整原段与前后文。单句、无法安全分句或已有段落译文时保留全文，不机械截字。搜索单词、连续短语或同段全部词，匹配具体表面词形；不冒充词元、中文语义或全网搜索。
2. 新增只读 `/api/v1/corpus/examples`。必须登录，显式无效Authorization不回退cookie，所有响应private/no-store。Zod校验参数和DTO，application调用专用repository。直接查询已发布、清权的文章及已审核媒体片段，不依赖出现索引，不生成短语条目或审核结论。历史search/browse API保留。
3. 文章使用最新已发布版本、媒体使用currentVersion；私人生成文章仅当前所有者可见。前后文只来自同一可见版本的合格片段。每次读取重验来源、发布、版权、所有权；不缓存私人内容。默认按来源轮转，稳定分页与总量来自同一SQL语句快照。
4. 原文保留标点与重音，匹配词高亮；已有媒体译文可显示/隐藏，文章无现成译文则如实缺省，不自动调用AI。朗读与对照使用实际显示句，避免显示短句却朗读整段。浏览器合成朗读明确区别于原音；切查询/页/过滤/卸载取消，旧回调隔离，错误可恢复。
5. 用户可临时加入最多三条句子作对照，刷新清除，无收藏/能力证据写入。来源入口文章带版本并定位段落，媒体明确传递时间/真实segment index；显式位置优先历史进度。

## 替代方案

- 删除语料页：降低导航负担，但丢失从真实输入确认表达和媒体点词的跨来源查询。
- 继续短语聚类：仍与短语手册混淆，依赖不完整的出现索引，默认切片质量不能保证。
- 生成新的AI例句库：与手册重复，无法回答“在我看的资料里怎么说”，还增加审核和费用。

## 后果

新入口查询当前可见内容段落，语料增长后应测量SQL成本再决定专门全文索引；当前不迁移、不跨服务。完整字幕片段不一定是完整语法句，标作“原句 / 原段”，前后文弥补来源自然切分。无真实源音频裁剪、批量下载或自动翻译。旧索引用于精确entry深链接限定，不再作为自由查询唯一来源。
