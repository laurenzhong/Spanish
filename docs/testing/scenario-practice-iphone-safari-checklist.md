## Safari 标签页

- [ ] 首次进入场景实战时，麦克风权限说明清楚；允许后可以录音。
- [ ] 拒绝麦克风后不循环弹窗，页面明确提供文字输入。
- [ ] 按住录音、松开发送；手指滑出或系统取消手势时不提交半段录音。
- [ ] 来电、锁屏、切到后台或切换标签页会释放麦克风，回到页面后显示可恢复提示。
- [ ] 蓝牙或有线耳机切换导致音轨结束时，不保存半段录音，也不产生负面能力证据。
- [ ] 转写失败、超时或低置信度时保持中立，并允许重试或改用文字。
- [ ] 中文与西班牙语键盘切换、候选栏展开和横竖屏切换后，输入框及发送按钮仍完整可见。
- [ ] 键盘弹出时当前焦点不被固定 Composer 遮挡；收起键盘后布局恢复。
- [ ] 顶部刘海/灵动岛与底部 Home Indicator 不遮挡导航或操作按钮。
- [ ] 320、375、390、414 CSS px 宽度均无水平滚动；200% 文本缩放后主要动作仍可用。
- [ ] Provider 首次失败且未显示人物文字时只切换一次；已经显示文字后失败不拼接第二个模型。
- [ ] Provider 不可用提示包含重试、改选或恢复自动选择的动作，学习断点仍存在。

## 添加到主屏幕 PWA

- [ ] 主屏图标、名称 `Sueño`、启动背景和主题色正确。
- [ ] 从主屏启动为 standalone；登录态与深链返回行为符合预期。
- [ ] 实战中退出 PWA 再进入时，稳定断点恢复，旧 generation 回调不会覆盖当前状态。
- [ ] PWA 前后台切换、系统内存回收后重启，不把未完成消息或录音当作成功。
- [ ] Provider 设置页可滚动、可聚焦、可保存，底部安全区不遮挡选择控件。
