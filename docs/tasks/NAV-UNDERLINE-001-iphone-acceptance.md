# 滑动下划线真机验收清单（iPhone Safari）

任务：`NAV-UNDERLINE-001`（`6618274`）、`-002`（`b20bf94`）、`-003`（`8f3777c`）。
本机预览服务：`npm`/`pnpm exec next dev --hostname 0.0.0.0 --port 3120`，局域网地址 `http://192.168.8.210:3120`（IP 由 DHCP 分配，换网络后需重新查询 `Get-NetIPAddress`）。该服务带 `AUTH_E2E_ENABLED=1`，iPhone Safari 首次访问时按下面第 0 步写入测试会话 cookie，即可直接看到登录后的页面。

## 0. 准备（仅一次）

1. iPhone 与本机连同一个 Wi-Fi（`192.168.8.x`）。
2. Safari 打开 `http://192.168.8.210:3120/`。
3. 打开一条带测试会话的地址，让 Safari 带上登录态：在地址栏输入
   `javascript:document.cookie="spanish-e2e-user=00000000-0000-4000-8000-000000000001;path=/"`，
   然后刷新（若 Safari 屏蔽书签脚本，可改为在 Mac 上用同一网络访问一次再继续）。
4. 确认底部/侧边导航可见，页面不是登录页。

## 1. 阅读区 `/read`

- [ ] 「文章・词汇・短语・语料・已保存」中当前项下划线**只有一条**，且与下方搜索框不相贴（间距应与桌面一致，无横线）。
- [ ] 手指按住并滑过其他项：下划线跟到手指所按的那一项（触摸屏没有 hover，验收的是按下即移动）。
- [ ] 松手不跳转时下划线回到当前页；点击其他项后新页面下划线落定在它上面。
- [ ] 顶部与搜索框之间、搜索框与首篇文章之间都不出现多余横线。

## 2. 已保存 `/read/saved-items`

- [ ] 「全部・文章・保存词语 / 短语・高亮」只有一条下划线，位于当前类型下。
- [ ] 点「高亮」后下划线移动并落定，列表切换为该类型。
- [ ] 标签条在窄屏可横向滚动，滚动时下划线仍贴在所选标签上（不飘到别处）。

## 3. 学习页 `/learn`

- [ ] 「全部・视频・播客」下划线为赤陶色、较粗，压在页头横线上（不在文字下方悬空）。
- [ ] 点「视频」：下划线跟过去，页面原地切换频道（不整页刷新），期间出现「正在切换内容…」。
- [ ] 切换后地址变为 `/learn?kind=video`，返回键回到「全部」。

## 4. 公开首页 `/`（先在 Safari 退出登录态或使用无痕标签访问）

- [ ] 页头「产品方式 / 阅读 / 登录」有珊瑚色下划线，静止时在「产品方式」下。
- [ ] 按下其他项时下划线跟过去，移开后回到「产品方式」。
- [ ] 「进入学习」胶囊按钮本身不带下划线；手机宽度下只显示「登录」+「进入学习」时，下划线落在「登录」上，不落在看不见的项上。

## 5. 我的 `/me`

- [ ] 「能力与活动・关系隐私・数据与隐私・偏好设置」下划线只在**当前**分区下（旧缺陷是恒停在第一项）。
- [ ] 点「关系隐私」：下划线移动、分区切换、地址变为 `#profile-relationships`。
- [ ] 点 Safari 返回键：回到「能力与活动」，下划线跟着回来。
- [ ] 下划线颜色与页面主题一致（深色外观下仍可见）。

## 6. 全局

- [ ] 系统开启「减弱动态效果」后，下划线仍正确落位但不再滑动动画。
- [ ] 横竖屏切换、放大页面后，下划线不偏移、不残留第二条。
- [ ] 键盘（外接键盘 Tab）移动到导航项时下划线跟随，焦点环可见。

## 反馈方式

任何一项不符预期时，记录：页面、项名、当时的动作（按下/滑动/点击/返回）、是否开着减弱动态效果、以及截图。预期需要修改时按任务重新开一条 `NAV-UNDERLINE-004`，不在此清单内顺手改代码。

## 已知环境限制

- 本清单只在 iPhone Safari 真机上有效；桌面自动化（Playwright `product-shell`、`lexicon-library`、`learn-page` 与真实 Chrome 探针）已在实现提交中记录结果，不能替代本清单。
- `/learn` 与 `/read` 的内容来自本机 `.env` 指向的数据库；没有真实数据时只验证下划线行为与空状态，不把空状态当成缺陷。
