## 问题处理边界

- 阻塞、数据隔离、证据污染、隐私泄漏和人物事实冲突：立即暂停扩大使用，先建立单独修复任务和回归测试。
- 可复现的流程/交互问题：单独建立一个任务 ID；不在本日志里混入未批准的功能扩展。
- 主观偏好或低频不自然：先记录，至少观察两次后再决定是否改动。
- 真实 iOS 录音、权限、键盘、安全区、生命周期和通知问题：在 Mac/Xcode 与真机条件具备后单独验收。
