# Sueño 公开产品页视觉重设计实施计划

- 任务总 ID：`PUBLIC-HOME-001`
- 日期：2026-09-20
- 状态：已批准方向；`PUBLIC-HOME-001B` 至 `001D` 首版已完成，等待用户视觉 review
- 目标分支：`codex/public-home-001`
- 规格：[公开产品页视觉重设计规格](../superpowers/specs/2026-09-20-public-home-visual-redesign-design.md)

## 1. 范围

重做匿名公开入口 `/` 的视觉、媒体、动效、响应式和质量验收。保留现有登录入口、产品路由、品牌名称和产品不变量；不修改业务 API、认证、数据库、评分和登录后产品页面。

## 2. 分阶段任务

每个任务使用独立分支/提交；不得把多个任务混成一个实现提交。

### `PUBLIC-HOME-001A`：概念和素材门禁

- 输出：分段视觉概念、首屏媒体候选、文案锁、素材授权/来源表。
- 首屏概念必须同时说明桌面和移动端构图，且露出下一段内容。
- 真实产品画面优先来自当前 `/learn`、媒体详情或 `/chat`；生成图不能冒充产品 UI。
- 通过条件：用户确认首屏、章节顺序、色彩、媒体 treatment 和动效强度。
- 当前限制：ImageGen skill/tool 不可用；本轮以浏览器渲染概念稿和代码原生产品预览替代，已记录限制。

### `PUBLIC-HOME-001B`：页面骨架和设计令牌

- 文件范围：`app/page.tsx`、必要的公开页 Client Components、公开页 CSS/token。
- 交付：导航、首屏、语境循环、产品证明、关系/隐私、收束 CTA、页脚。
- 约束：服务端保留完整文本；不把整页改为 Client Component；不新增业务数据依赖。
- 验证：静态渲染、链接路径、键盘导航、移动端无溢出。

### `PUBLIC-HOME-001C`：真实产品媒体和渐进增强动效

- 交付：真实截图/录屏、poster、响应式裁切、CSS timeline 和 Motion 局部动效。
- 首版不引入 Three.js、Lenis 或 GSAP；只有出现明确的 pinned scrollytelling 需求时才重新决策。
- 验证：静态 fallback、低带宽、`prefers-reduced-motion`、隐藏标签页暂停、媒体尺寸稳定。

### `PUBLIC-HOME-001D`：质量验收和视觉回归

- 视口：`375×812`、`768×900`、`1024×900`、`1440×900`。
- 检查：截图、文本换行、焦点、对比度、媒体 poster、页面错误、首屏性能和横向溢出。
- 命令：目标 ESLint、`pnpm typecheck`、相关 Vitest、目标 Playwright、`git diff --check`、必要时 `pnpm build`。
- 输出：视觉差异台账，至少记录五个对比点；真实 iPhone Safari 另列未执行项。

## 3. 依赖与风险

| 风险 | 处理 |
| --- | --- |
| ImageGen 工具不可用 | 不伪造生成结果；使用真实产品素材和浏览器概念稿，并在交接中明确限制 |
| 真实产品截图包含个人数据 | 仅使用脱敏 fixture 或静态录制；不把私人会话、Token、真实账户信息放入公开素材 |
| 首屏视频过大影响 LCP | poster 优先、短视频、明确尺寸、延迟加载和静态 fallback |
| 动效与登录后产品壳冲突 | 所有选择器限定在 `.public-home`，不修改全局学习主题和产品壳布局 |
| 营销文案产生未批准产品承诺 | 使用规格中的 copy lock；新增 claims 需用户明确批准 |

## 4. 不在本计划中的内容

- 支付、订阅、价格和公共注册。
- 登录后学习页的 Hero、推荐或导航重做。
- 新增内容、角色、媒体、分析埋点或 Provider。
- 生产部署、真实用户数据采集、真实 iPhone 验收。

## 5. 交接定义

交接必须包含：任务 ID、分支和 HEAD、修改文件、Commit、运行过的命令及结果、未执行检查及原因、概念/素材限制、用户验证方式和下一项开始条件。未部署、未真机验收、未使用真实私人会话必须如实标记。
